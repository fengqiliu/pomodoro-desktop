## 1. 引言

### 1.1 编写目的

本文档基于项目源码逆向整理，完整描述 Pomodoro 桌面番茄钟 v2.0 的功能需求与非功能需求，作为开发、测试与验收的基准。预期读者：开发人员、测试人员、维护者。

### 1.2 项目背景

Pomodoro 是一款扁平风格的桌面番茄钟，定位「专注、安静、不打扰」。v2.0 基于 Tauri 2 构建单窗口桌面应用，前端为 React 18 + TypeScript + Vite，桌面端由 Rust 原生计时模块负责倒计时截止与完成事件；同一前端代码可在普通浏览器中以降级模式运行。

### 1.3 术语定义

| 术语 | 定义 |
| --- | --- |
| 阶段（Phase） | 计时的三种状态之一：`focus`（专注）/ `short`（短休息）/ `long`（长休息） |
| 番茄（Pomodoro） | 一次完整完成的专注阶段 |
| 长休周期（Cycle） | 两次长休息之间累计的已完成专注次数（`cycleFocusCount`） |
| 每日进度（DailyProgress） | 当天日历日绑定的完成番茄数与专注分钟数，跨日自动归零 |
| 代际（Generation） | 计时器单调递增的序号，用于使旧的取消/完成操作失效 |
| 桌面端 / 浏览器端 | Tauri 原生窗口运行环境 / 普通 WebView 浏览器运行环境（`isDesktop()` 判定） |

## 2. 总体描述

### 2.1 产品定位

单窗口（380×580，不可缩放、不可最大化）桌面番茄钟，提供「专注 / 短休息 / 长休息」三阶段循环计时，配合任务清单、7 天统计、白噪音、系统托盘与原生通知，帮助用户以番茄工作法管理专注时间。

### 2.2 用户特征

- 目标用户：需要在桌面端进行时间管理的个人用户。
- 使用场景：工作/学习时前台专注，或关闭窗口后在托盘驻留继续计时。

### 2.3 运行环境

| 环境 | 要求 |
| --- | --- |
| 桌面端（完整功能） | Windows（WebView2 + MS C++ Build Tools）、macOS（Xcode CLT）、Linux（webkit2gtk 等系统库）；Tauri 2 运行时随应用打包 |
| 浏览器端（降级功能） | 任意现代浏览器；Vite 开发服务 `:1420`；置顶/全局快捷键/原生通知/托盘自动降级为 no-op |
| 构建环境 | Node.js 18+、Rust 稳定工具链（1.77+） |

### 2.4 设计与实现约束

1. **平台抽象约束**：所有原生能力调用必须经由平台抽象层（`src/infrastructure/platform/`），组件禁止直接 import `@tauri-apps/*`。
2. **持久化约束**：状态仅保存在 localStorage，带版本后缀键；修改持久化结构时递增键后缀，不做迁移。
3. **双端一致**：浏览器端与桌面端共享同一套 React 界面与领域规则；计时机制允许适配器差异。
4. **无第三方 i18n 库**：手写中/英字典。
5. **无音频资源文件**：白噪音与提示音均由 WebAudio 实时合成。
6. **样式约束**：主题基于 CSS 变量；阶段强调色通过行内样式覆盖 `--accent`。

### 2.5 假设与依赖

- 假设用户系统时间基本准确（计时基于墙上时间戳）。
- 依赖 Tauri 2、`tauri-plugin-global-shortcut`、`tauri-plugin-notification`；前端依赖 React 18、Vite 6、Vitest 4（仅测试）。

## 3. 功能需求

> 编号规则：`FR-<域><序号>`。每条需求附「验收标准」。标注〔桌面端〕的需求在浏览器端自动降级。

### 3.1 计时核心

**FR-C1 三阶段计时**
应用提供专注 / 短休息 / 长休息三个阶段，环形进度条随剩余时间填充，且随阶段变色（专注红 `#ff5b5b`、短休绿 `#3ecf8e`、长休蓝 `#4a90e2`）。
验收：阶段切换后强调色与环形进度立即更新；倒计时显示 `MM:SS`。

**FR-C2 可配置时长**
专注 1–120 分钟、短休 1–60 分钟、长休 1–60 分钟均可设置（默认 25/5/15）。
验收：修改设置后，处于暂停/空闲状态的当前阶段倒计时自动对齐新时长；正在计时的阶段不受影响（不得被悄悄拉长/缩短）。

**FR-C3 番茄循环**
每完成 `N`（默认 4）个专注自动进入长休息，否则进入短休息；休息完成后回到专注。跳过（Skip）操作不累计番茄数、不推进长休周期。
验收：`cycleFocusCount` 连续计数，达到 N 后归零并进入长休；跳过专注不改变计数。

**FR-C4 跨日延续**
长休周期计数跨日期延续，不受每日统计归零影响。
验收：午夜后 `cycleFocusCount` 保持原值，而 `completedToday/focusMinutesToday` 归零。

**FR-C5 手动控制**
提供开始/暂停（Toggle）、重置（Reset，恢复当前阶段满时长）、跳过（Skip）、直接切换阶段（Switch Phase）四种操作。
验收：各操作即时生效且不引发计时漂移；暂停后再开始从剩余时间继续。

**FR-C6 自动衔接**
可分别设置「专注后自动进入休息」与「休息后自动开始专注」（默认均关闭）。
验收：开启后阶段完成无需手动点击即自动开始下一阶段倒计时。

**FR-C7 计时精度**
倒计时必须基于墙上时间截止点计算剩余时间，而非 interval 累加；系统休眠、后台节流、interval 抖动不得造成计时漂移。
验收：长时间后台驻留后剩余时间与真实流逝时间一致。

**FR-C8 窗口标题倒计时**
运行中窗口标题实时显示 `MM:SS · 阶段名`，暂停/空闲时显示应用名。
验收：任务栏/Dock 可读出剩余时间。

### 3.2 任务清单

**FR-T1 任务增删改**
可添加（标题非空，新任务插入列表最前）、删除、勾选完成/取消完成、一键清除已完成任务。
验收：删除当前专注任务后当前任务置空。

**FR-T2 当前专注任务**
可将任一任务设为「当前专注任务」；计时页显示其标题；每完成一个番茄，当前任务的番茄计数 🍅 +1。
验收：同一时刻至多一个当前任务；统计口径与今日总数互不影响。

**FR-T3 任务状态持久化**
任务列表（含番茄计数）跨重启保留。

### 3.3 统计

**FR-S1 今日汇总**
计时页展示：今日番茄数、今日专注分钟、距下次长休息还需的番茄数。

**FR-S2 7 天统计**
统计页以柱状图展示近 7 天数据，可在「番茄数 / 专注分钟」两种口径间切换；汇总卡片展示今日番茄、本周番茄、本周分钟。
验收：7 天窗口包含今日；无记录日以 0 值补齐；切换口径后图表与纵轴自适应。

**FR-S3 历史自动裁剪**
历史在启动、记录、导入时自动裁剪至近 60 天，防止存储无界增长。
验收：第 61 天前的记录被移除；图表只用近 7 天。

**FR-S4 每日自动重置**
今日计数在日期变化后自动归零，校验触发点包括：启动、午夜定时、窗口重新聚焦、页面变为可见、完成专注、持久化写入前（防御性校验）。
验收：长期驻留托盘跨日后数据不污染。

### 3.4 音频

**FR-A1 白噪音**
内置白/棕/粉三种噪音，WebAudio 实时合成（无音频文件），顶栏一键开关，音量 0–1（步长 0.05）可调；切换类型无缝衔接。
验收：浏览器端与桌面端均可播放；类型/音量设置持久化。

**FR-A2 完成提示音**
阶段结束时播放钟声（专注结束与休息结束使用不同音阶），可在设置中开关。

### 3.5 外观与窗口

**FR-V1 深色/浅色主题**
默认跟随系统 `prefers-color-scheme`，可手动切换；选择持久化。
**FR-V2 窗口置顶**〔桌面端〕
一键将窗口钉在最前（`setAlwaysOnTop`）；状态持久化，启动时与真实窗口状态同步。
**FR-V3 固定窗口**
窗口 380×580、居中、不可缩放、不可最大化、可最小化。

### 3.6 快捷键与托盘

**FR-K1 应用内快捷键**
`Space` 开始/暂停、`R` 重置、`S` 跳过；输入框/选择器/可编辑元素聚焦时及设置面板打开时忽略。
**FR-K2 全局快捷键**〔桌面端〕
默认 `CommandOrControl+Shift+P` 触发开始/暂停，可在设置中修改；组合键注册失败时给出错误提示且不影响应用运行；编辑时仅保存草稿，点击「完成」后才尝试应用。
**FR-Q1 系统托盘**〔桌面端〕
托盘图标常驻，左键单击切换窗口显隐；菜单含「显示/隐藏」「退出」。
**FR-Q2 关闭到托盘**〔桌面端〕
点击窗口关闭按钮不退出，隐藏到托盘，计时继续；仅托盘菜单「退出」终止进程。

### 3.7 通知

**FR-N1 原生通知**〔桌面端〕
阶段完成时发送系统通知（标题：专注完成/休息结束；正文：开始 <下一阶段>）；可在设置中开关；权限在首次实际发送时才请求。
**FR-N2 托盘驻留通知**
桌面端计时完成的通知与完成事件由 Rust 原生 worker 发送，不依赖 WebView 的 JS interval 或通知回调，窗口隐藏时依然可靠。
**FR-N3 去重**
若原生 worker 已发送通知，前端完成流程不再重复发送。

### 3.8 持久化与数据备份

**FR-P1 本地持久化**
全部业务状态（设置、任务、今日进度、周期计数、噪音偏好、历史）保存在 localStorage，跨重启保留。
**FR-P2 坏数据防御**
localStorage 数据损坏或缺失字段时，与默认值合并，不崩溃。
**FR-P3 数据导出**〔桌面端 + 浏览器端〕
一键将完整状态 + 历史序列化为 JSON 并复制到剪贴板；失败有 Toast 提示。
**FR-P4 数据导入**
从剪贴板读取备份并校验：载荷标识、state/history 结构不合法即拒绝（Toast 提示，不写入）；合法则与默认值合并、历史裁剪后写入并重载应用。剪贴板不可用时回退为弹窗粘贴输入。

### 3.9 国际化

**FR-I1 双语言**
内置简体中文（默认）与 English；设置中切换并持久化；`<html lang>` 同步更新。
**FR-I2 插值**
文案支持 `{param}` 参数插值（如「开始 {next}」「共 {total} 个任务 · 已完成 {done} 个」）。

## 4. 非功能需求

| 编号 | 类别 | 需求 |
| --- | --- | --- |
| NFR-1 | 计时精度 | 计时以墙上时间截止点（end timestamp）为准，`remaining = endAt - now`；不因 interval 节流/抖动漂移。桌面端由 Rust 按墙上时间判定完成。 |
| NFR-2 | 可靠性（通知链路） | 托盘驻留场景下完成通知由原生 worker 保证送达，不依赖前端定时器。 |
| NFR-3 | 健壮性 | 所有 Tauri 调用 best-effort（失败降级为 no-op，不崩溃）；localStorage 读写 try/catch；不可信导入数据经校验合并，坏数据不落盘。 |
| NFR-4 | 并发正确性 | 全局快捷键可能双击双触发：开始/暂停转换需串行化（in-flight 防抖）；完成流程防重入；旧代际回调被丢弃。 |
| NFR-5 | 双端一致 | 同一前端代码在桌面端与浏览器端均可运行；非桌面环境原生能力静默降级。 |
| NFR-6 | 性能/体积 | 1 秒一次的绘制循环仅在运行中激活；安装包（macOS dmg aarch64）约 2.9 MB。 |
| NFR-7 | 存储增长 | 历史保留近 60 天自动裁剪；图表仅用近 7 天。 |
| NFR-8 | 可用性 | 顶栏按钮带 aria-label 与 title；关键操作有 Toast（约 2.6 s 自动消失）；设置模态支持 Esc 关闭。 |
| NFR-9 | 安全 | CSP 由 Tauri 配置管理（当前 `csp: null`）；导入数据不执行任何动态求值；原生权限走 `capabilities/default.json` 白名单。 |
| NFR-10 | 可测试性 | 领域规则全部为纯函数（计时规则、统计、备份校验、原生计时器），可被 Vitest / cargo test 直接测试。 |
| NFR-11 | 质量门禁 | `tsc --noEmit` 零错误；前端 Vitest（4 文件 23 例）与 Rust 原生计时测试（5 例）全绿。 |

## 5. 数据需求

### 5.1 业务状态（`pomodoro-state-v3`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| settings | Settings | 专注/短休/长休时长、长休间隔、提示音、通知、两个自动衔接开关、全局快捷键、噪音类型/音量 |
| tasks | Task[] | `{ id: uuid, title, done, pomodoros }` |
| completedToday / focusMinutesToday | number | 今日番茄数 / 专注分钟数 |
| date | string | `YYYY-M-D`，每日重置判据 |
| cycleFocusCount | number | 自上次长休以来完成的专注数（跨日延续） |
| noise | NoisePref | `{ on, type, volume }` |

### 5.2 历史记录（`pomodoro-history-v1`）

`Record<dateKey, DayRecord>`，`DayRecord = { date, dayIndex(0..6), pomodoros, minutes }`；键为 `YYYY-M-D`。

### 5.3 偏好键

`pomodoro-theme`（light/dark）、`pomodoro-pinned`（"1"/"0"）、`pomodoro-lang`（zh/en）。

### 5.4 备份载荷

`{ app: "pomodoro", version: 2, exportedAt: ISO 时间, state, history }`；导入时校验 `app` 标识与 state/history 结构，state 经默认值合并、history 经 60 天裁剪。

### 5.5 默认值

| 项 | 默认值 |
| --- | --- |
| 专注/短休/长休时长 | 25 / 5 / 15 分钟 |
| 长休间隔 | 每 4 个番茄 |
| 提示音 / 通知 | 开 / 开 |
| 自动衔接（休息/专注） | 关 / 关 |
| 全局快捷键 | `CommandOrControl+Shift+P` |
| 噪音类型 / 音量 | 棕噪音 / 0.3 |
| 语言 / 主题 | 简体中文 / 跟随系统 |

「恢复默认」仅重置设置与噪音类型/音量，保留用户的噪音开关状态；同时重置计时器。

## 6. 界面需求

- **窗口布局**：顶栏（品牌 + 噪音/主题/置顶/设置按钮）→ 三标签页（计时 / 任务 / 统计）→ 内容区 → 底部 Toast 覆层。
- **计时页**：阶段切换胶囊、300×300 SVG 环形进度（中心倒计时 + 阶段名）、当前任务标题、控制按钮（重置 / 开始暂停 / 跳过）、三项今日汇总。
- **任务页**：添加输入框 + 添加按钮；任务列表（完成勾选、设为当前、番茄计数、删除）；页脚（总数/已完成）与「清除已完成」。
- **统计页**：三张汇总卡（今日 / 本周番茄 / 本周分钟）；近 7 天柱状图（SVG，300×150）+ 口径切换（番茄数/分钟数）；页脚（周均值或空态文案）。
- **设置模态**：通用（语言、时长、长休间隔、提示音、通知、自动衔接）/ 白噪音（类型、音量）/ 全局快捷键（草稿输入 + 错误提示）/ 数据（导出、导入）四组；底部「恢复默认」「完成」。
- **主题**：CSS 变量在 `:root`（浅色）与 `[data-theme="dark"]`（深色）定义；阶段强调色以行内 `--accent` 覆盖。

## 7. 验收与测试要求

1. 领域规则回归：Vitest 覆盖长休周期、跳过不计入、跨日重置、剩余时间计算、历史裁剪、备份往返。
2. 原生计时回归：cargo test 覆盖暂停保留墙上时间、仅最新代际可完成、取消失效、旧代际定向取消不干扰新计时器、worker 按截止时间送达完成。
3. 双端冒烟：桌面端 `npm run tauri dev`；浏览器端 `npm run dev`（:1420），确认原生功能降级、其余功能正常。
4. 完整构建：`npm run build` 通过 `tsc -b && vite build`；`npm run tauri build` 产出 .app/.dmg（Windows 产出 NSIS 中文安装包）。

## 8. 范围外（Out of Scope）

- 云同步、多设备、账号体系（备份仅为剪贴板 JSON 往返）。
- 服务器端或第三方统计服务。
- 除中英外的更多语言（字典结构可扩展但未内置）。
- 任务清单的项目/标签/截止时间等高级字段。
- 音频文件资源（一切声音实时合成）。
- 窗口尺寸自定义与最大化。
